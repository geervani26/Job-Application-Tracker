# Test Cases for Job Application Tracker

## 1. Add Application
- [ ] Fill out all required fields and click "Add Application".
- [ ] Verify the item appears in "All Applications" and on the Dashboard.
- [ ] Verify the KPI numbers and charts update correctly.

## 2. Edit Application
- [ ] Click the pencil icon (✏️) next to an application.
- [ ] Verify the form is populated and the title changes to "Edit Application".
- [ ] Change the status to "Interview" and click "Save Changes".
- [ ] Verify the table and dashboard reflect the updated status.

## 3. Delete Application
- [ ] Click the trash icon (🗑️) next to an application.
- [ ] Confirm the prompt.
- [ ] Verify the item is removed from the table and dashboard.

## 4. Export / Import
- [ ] Click "Export" and verify a `.json` file downloads.
- [ ] Clear local storage (or add new items) and click "Import".
- [ ] Select the downloaded file and verify the data restores correctly.

## 5. Profile Update
- [ ] Click the profile badge in the top right.
- [ ] Change the name and role.
- [ ] Verify the sidebar/header updates and persists on page reload.
