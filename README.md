# Job Application Tracker

A clean, modern dashboard built with vanilla HTML, CSS, and JavaScript to help you track your job search process.

## Features

- **Dashboard Overview:** Visualize your application stats, interview rates, and recent activity.
- **Application Management:** Add, edit, and delete job applications easily.
- **Analytics:** View a dynamic doughnut chart (powered by Chart.js) showing your applications by status.
- **Data Management:** Export your applications as a JSON backup or import them later.
- **Local Storage:** Your data is saved securely in your browser's local storage. No backend required.

## Project Structure

- `index.html`: The main UI layout.
- `style.css`: All styling, including the "Lavender Dream" theme colors and responsive layout.
- `script.js`: App logic, local storage management, and DOM manipulation.
- `tests/test-cases.md`: Manual testing checklist (see below).
- `assets/`: Folder for icons and images (currently empty placeholders).

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
